# ai-system-reliability-monitor
# AI-Powered System Reliability & Monitoring Platform

An AI-driven monitoring platform designed to detect abnormal
system behavior, predict potential failures, and provide
real-time reliability insights.

## Features

- Real-time system metrics monitoring
- CPU, memory and disk monitoring
- AI-based anomaly detection
- Failure-risk prediction
- Automated alerts
- Reliability dashboard
- REST API
- Docker support
- Automated testing

## Tech Stack

Python | FastAPI | Scikit-learn | Pandas | Streamlit | Docker

## How It Works

1. Collect system metrics
2. Process and normalize data
3. Detect anomalies using ML
4. Calculate failure risk
5. Generate alerts
6. Display results on dashboard
